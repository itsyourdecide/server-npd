# Безопасная PXE-переустановка узла

- Статус: current
- Последняя проверка процедуры: 2026-09-05
- Last tested: 2026-08-07
- Назначение: разрешить ровно одну автоматическую переустановку известного узла
- Источник истины для: безопасного использования install-once механизма PXE

## Воздействие

Процедура уничтожает установленную ОС и локальные данные выбранного узла.
Ожидаемый простой — до завершения установки и повторного применения Ansible.
Обычный PXE boot без install-once флага не должен запускать destructive профиль.

## Предпосылки

- пользователь или владелец данных подтвердил переустановку конкретного узла;
- hostname, LAN MAC, IP и физический порт сверены минимум по двум источникам;
- нужные данные сохранены вне целевого диска;
- доступна IPMI/локальная консоль;
- `pxe01` (`10.10.80.10`) и Nginx/TFTP прошли health-check;
- CSV inventory и выбранный Kickstart проверены;
- массовая операция сначала прошла dry-run.

## Процедура

1. Сохранить текущее состояние узла и вывести его из HTCondor.
2. На `pxe01` перейти в каталог действующей PXE-конфигурации.
3. Посмотреть справку скрипта и выполнить dry-run для точного MAC:

```bash
./create-install-once.sh --help
```

4. Создать install-once флаг только для подтверждённого LAN MAC. Проверить, что
   имя файла в `/srv/pxe/http/install-once/` соответствует нормализованному MAC.
5. Один раз загрузить узел по сети и наблюдать консоль, Nginx access log и
   watcher.
6. Убедиться, что после первого HTTP 200 флаг перемещён в `used/` и повторный
   PXE boot возвращает безопасное меню.
7. После первого входа продолжить по [runbook ввода узла](provision-node.md).

Repository copy скриптов и профилей находится в [`infra/pxe/`](../../infra/pxe/).
Runtime copy на сервере — `/srv/pxe`; её совпадение с репозиторием проверяется
после deployment.

## Стоп-критерии

- MAC, hostname, IP или порт не совпадают;
- выбранный диск нельзя однозначно отличить от диска с данными;
- install-once флаг появился для другого узла;
- watcher не переместил использованный флаг;
- консоль недоступна или установка пошла не по ожидаемому профилю.

При срабатывании стоп-критерия удалить только созданный для этой операции
неиспользованный флаг, отменить PXE boot через консоль и не перезагружать узел
повторно. Уже стёртую ОС автоматически откатить нельзя; восстановление идёт из
резервной копии или повторной установки.
