# История операций

- Статус: historical index
- Последняя проверка структуры: 2026-09-05
- Назначение: навигация по неизменяемым датированным записям выполненных работ
- Источник истины для: выбора журнала по периоду

## Журналы

- [2026-07](operations-2026-07.md) — 55 записей, 2026-07-01—2026-07-10.
- [2026-08](operations-2026-08.md) — 21 запись, 2026-08-05—2026-08-28.

Записи внутри файлов расположены от старых к новым. Исходный файл до разделения
сохранён как [legacy-журнал](../../archive/superseded/cluster_operations_log-legacy.md).

История показывает состояние на дату операции. Для текущего состояния нужно
использовать [current state](../current-state.md), а для незавершённых работ —
[open issues](../project/open-issues.md).

## Как добавлять запись

Используйте правила и шаблон из
[руководства по документации](../documentation-guide.md). Новый месяц получает
отдельный файл `operations-YYYY-MM.md`; запись добавляется в конец только после
проверки результата операции.
