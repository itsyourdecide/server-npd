# Рабочая папка

Дата создания: 2026-07-01

Назначение: сырые логи и сохранённые конфиги по узлам, отдельно от curated-журнала `../cluster_operations_log.md`.

## Структура

```text
work/
  pve01/
    logs/      сырой вывод команд по датам, например 2026-07-01-checks.log
    configs/   сохранённые конфиги: netplan, vmbr, OPNsense export и т.д.
  switch1/
    logs/
    configs/   show config, show vlan и т.д.
  switch2/
    logs/
    configs/
  scripts/     вспомогательные скрипты, общие для нескольких узлов
```

Новые узлы (pve02, pve03, asus01 и т.д.) добавляются такой же парой logs/configs при вводе в PoC.

Итоговые решения и краткое описание изменений по-прежнему фиксируются в `../cluster_operations_log.md` по шаблону оттуда — эта папка хранит только сырые данные и артефакты.
