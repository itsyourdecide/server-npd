# Рабочая папка

Дата создания: 2026-07-01
Последняя проверка структуры: 2026-09-05
Статус: transitional

Назначение: переходная заглушка после миграции прежней рабочей папки.
История операций находится в [`docs/history/`](../docs/history/README.md).

> Новые live-конфигурации здесь не создавать. После этапа 6 они должны
> находиться в `infra/` или Ansible, а сырые доказательства — в `evidence/`.

## Куда перенесено содержимое

- действующие repository copies — в [`infra/`](../infra/README.md);
- замеры, сетевые выгрузки и снимки узлов — в
  [`evidence/`](../evidence/README.md);
- повторяемые helper-скрипты — в `scripts/`;
- хронология изменений — в [`docs/history/`](../docs/history/README.md).

Пустые локальные подкаталоги могут остаться после `git mv`, но не являются
частью репозитория и не должны использоваться для новых файлов.

Новые результаты операций фиксируются в журнале соответствующего месяца по
[правилам документации](../docs/documentation-guide.md). После завершения
миграции этот каталог можно удалить отдельным изменением.
