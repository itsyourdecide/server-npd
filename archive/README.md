# Архив

Здесь лежат документы, которые **выполнили свою роль и больше не отражают
текущее состояние**, но сохранены как история проекта. Их не используют как
инструкции. Актуальная точка входа — [корневой README](../README.md).

## Содержимое

- `today_plan_pve01_opnsense_switch.md` — одноразовый план сессии 01.07.2026
  (pve01 + OPNsense + switch). Полностью выполнен; продолжение отражено в
  [истории за июль](../docs/history/operations-2026-07.md). Перенесён в архив
  03.07.2026.
- `superseded/cluster_operations_log-legacy.md` — исходный монолитный журнал до
  разделения на месяцы; сохранён для проверки полноты миграции.
- `technical_passport_head01_hp3500yl_supermicro_v05.md` — техпаспорт старого
  Ubuntu `head01` до переустановки в Proxmox. Актуальное состояние нужно искать
  в [current state](../docs/current-state.md), а аппаратные факты будут
  перенесены в inventory.

Дополнительные каталоги:

- `completed-plans/` — выполненные одноразовые планы, которые нельзя применять
  как текущие инструкции;
- `superseded/architecture-2026-07/` — исходная июльская архитектура,
  implementation plan и лабораторный PoC, заменённые документами в `docs/`.
