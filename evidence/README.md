# Evidence — снимки и результаты проверок

- Статус: historical evidence index
- Последняя проверка структуры: 2026-09-05
- Назначение: хранить датированные необработанные доказательства состояния
- Источник истины для: происхождения логов, замеров и снимков на указанную дату

## Структура

- `measurements/` — hardware, power, thermal и нагрузочные замеры.
- `network-snapshots/` — выгрузки сетевого состояния по датам.
- `node-snapshots/<node>/` — логи и конфигурационные снимки отдельных узлов.

Evidence подтверждает только состояние в момент сбора. Оно не заменяет
[current state](../docs/current-state.md) и не является действующей
конфигурацией. Авторитетные repository copies находятся в
[`infra/`](../infra/README.md) или Ansible.

Новые материалы помещаются в датированный каталог без секретов. После
добавления исходный снимок не редактируется; пояснение и результат операции
записываются в [history](../docs/history/README.md).
